Install and get started

The 19 October 2026 handover: Windows till, Basket Review extension and Android mobile app.

Make a sale

Scan, review, take payment and print.

Check and update stock

Find stock, count it, verify changes and confirm.

Print product labels

Roll or A4, copies, QR codes and photos.

1. Install the Windows update

  1. Download the handover ZIP supplied by your support contact and choose Extract All.
  2. Back up your existing Posnic data, finish open transactions and close Posnic.
  3. Run Install Posnic.exe from the extracted folder, then open the installed Posnic shortcut.
  4. Use your existing shop and branch. Ask support before connecting a second till; do not create a duplicate shop.
  5. Open Extensions, import Extension/Basket Review Extension.zip, and apply the update/restart when prompted. Import the ZIP as supplied.

The installer is an unsigned support build. If Windows blocks it, contact your support person to verify the file.

2. Set up the phone

Download Posnic Mobile v0.3.0-beta.30 (Android ARM64)

  1. Open the APK on a compatible Android phone and follow Android’s installation prompts.
  2. Choose Posnic Cloud account, sign in and approve the phone in the browser. Return to the app and select the correct shop and branch.
  3. For a local or Community shop, use Connect a local or Community shop with the connection details supplied by support.
  4. Allow the product list to load. Check the shop name and a few products before entering sales or stock changes.

This is a beta mobile release. Keep pending sales and stock drafts until their server result is confirmed.

3. Quick verification

  • Check product names, prices and VAT on a few known items.
  • Check the actual receipt printer and paper size. Print one label before a batch.
  • Check stock in Inventory → Items; use the separate stock guide for corrections.
  • Review the first real completed sale in sales history. If printing fails, reprint that receipt rather than taking payment again.

What is included

Windows Posnic 1.9.2 support build 119d9911; Basket Review 0.1.1-rc.39; mobile download link; offline copies of these guides and a file checksum manifest.

This build adds clearer label customization, optional barcodes, QR codes and product photos, plus direct thermal cutter choices. The supplied EXE contains these changes; a website or another till may need its own update.
